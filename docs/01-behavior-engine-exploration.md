# 行为发动机：从"忍不住"出发的游戏设计探索

> 第一轮：发散 → 审视 → 收敛。文中所有关于体验的判断都是假设，最终要靠行为测试决定。
> 2026-09-26

## 先说结论

1. **最值得占的新地盘是"谁能看见什么"。** 24 个方向里最强的两个都不往世界里加东西，只改变可见性：
   - **盲区**：别人能看见你看不见的自己（你的死法写在你背上）。
   - **偏见的裁判**：惩罚取决于谁被看见，而不是谁干的（大人只看见你还手）。

   可见性几乎不花美术，却直接生产误会、冤屈、共谋和戏剧反讽——这些正是"卧槽你看刚才"的原料。对小团队来说，**设计"谁能看见什么"比设计"世界里有什么"便宜得多**。
2. **"让朋友不断给我想扇他的理由"可以系统化**：他占了我便宜 + 我知道是他 + 他在嘚瑟 + 我现在够得着 + 扇下去有点风险。世界规则负责持续制造这五个条件，扇巴掌按钮只是出口（见 0.5）。
3. 两条会改变设计决策的原则：**不要把自发行为做成任务**（加奖励反而会削弱它）；**把挫败感导向人，而不是系统**。
4. 建议做灰盒的种子。这不是排名，而是一组覆盖不同风险的测试：
   - A **盲点**：每个人身上挂着一条自己看不见、别人都看得见的死亡条件。
   - B **还手才被看见**：一个只惩罚它看见的动作的权威（车后座、教室、开会）。
   - C **你欠我一次**：任何帮助都会生成债条，债主可以随时兑现，强制你做一个动作。
   - D **坑你的坑归你了**（异步）：被哪个陷阱杀死，就得到那个陷阱，拿去坑下一个人。
   - 外卡 **言出法随**：世界按字面实现你说的话（先由真人扮演 AI 来测）。
5. **最便宜的第一步只需要一个晚上**：用便利贴在客厅里玩 A，找一个真人扮演"后视镜里的爸爸"玩 B。它们能告诉我们的东西，比继续头脑风暴更多。

## 0. 人为什么会忍不住

### 0.1 一个工作模型

"忍不住"不是某一种情绪，而是两个条件同时成立时的状态，外加一个放大器：

**一个悬着的缺口 × 一个就在手边的动作；有人在看时，冲动会被放大。**

- **缺口**：好奇（不知道会怎样——Loewenstein 的信息缺口理论说的就是这种"知道自己不知道"的痒）、不公（凭什么）、面子（被看扁了）、欲望（再多一点 / 他有我没有）、关系（欠了人情 / 被冒犯了）、秩序（歪的想扶正，整齐的想推倒）、边界（到底能过分到什么程度）。
- **就在手边**：一个动作、一秒钟、不用准备。缺口再大，如果要走三分钟才能动手，冲动也会散掉。
- **有人在看**：见证让行为的价值翻倍——面子、炫耀、看热闹、恶作剧的回报，都来自别人的反应。

还需要一个框：**良性冒犯**（McGraw & Warren 的幽默理论：既违规又安全的事才好笑）。游戏天然是安全框，所以推人、骗人、坑人会从"冒犯"变成"好笑"。这是恶作剧类设计成立的前提，也是它的边界：一旦损失变得真实（长期进度、金钱、人格羞辱），好笑就会变成愤怒。

### 0.2 从一次冲动到一台发动机

一次冲动只产生一次行为。要变成"行为自己制造下一个行为"的发动机，还需要：

| 条件 | 含义 | 例子 |
|---|---|---|
| 闭合 | 后果在某人身上打开一个新的缺口 | 被推的人得到了一个"报复"缺口 |
| 守恒 | 有东西保证它不会熄火 | 捉人游戏里永远有一个"鬼" |
| 阻尼 | 有东西防止它失控或一边倒 | 报复升级到双方都吃亏；集体惩罚 |
| 归因可调 | 清楚到能报复，模糊到能甩锅 | 受害者知道是谁，旁人不一定知道 |
| 见证 | 行为发生时有人在看 | 共享画面、旁观的死者 |
| 外人可读 | 观众在画面里看得见关键的不对称 | 观众看得到标签，角色看不到 |

最后一条是外部传播的关键：**让观众比玩家知道得多。** 恐怖片观众会喊"别进去"，8番出口的弹幕会喊"回头"。这种"忍不住想喊"，就是观众版的手贱。

### 0.3 几条会改变设计决策的证据与判断

- **不要把自发行为做成任务。** 过度理由效应（Lepper 等，1973）：给本来就爱做的事加上外部奖励，会削弱之后的内在兴趣。"扇朋友 0/3"会把恶作剧变成打卡。系统该提供的是理由和机会，而不是奖励。
- **明码标价会挤掉社会情绪。** Gneezy & Rustichini（2000）：托儿所对迟到接孩子的家长罚款后，迟到反而变多，撤掉罚款也回不去了——"不好意思"被换成了"我付过钱了"。任何想把人情、愧疚、承诺做成数值的设计，都要小心这一点。
- **惩罚让合作活下去。** Fehr & Gächter（2000）：公共物品实验中，没有惩罚手段时合作逐轮下滑；允许自费惩罚搭便车者后，合作能维持在高位，而且人们确实愿意自掏腰包去罚。推论：合作游戏里给玩家互相惩罚的手段，不一定破坏合作，反而可能是维持合作的方式——同时它也是报复的合法出口。
- **把挫败感导向人，而不是系统。**（这是判断，不是实验结论。）系统造成的不公让人想退出；朋友造成的不公让人想再来一把。好的"不公"应该有一个人类肇事者。

### 0.4 你的清单之外的基础冲动

| 冲动 | 一句话 | 规则钩子 |
|---|---|---|
| 知情者的快感 | 全屋都知道，只有他不知道 | 让某条信息只对当事人隐藏 |
| 共谋 | 一起瞒着一个人，旁观者会结成同伙 | 旁观者也能从隐瞒中得利 |
| 擦边挑衅 | "我没碰你啊"——手指悬在对方脸前 | 规则边界上的合法骚扰 |
| 冤屈 | "是他先动手的！" | 惩罚只看得见后半段 |
| 告状 | 把权威的注意力当武器 | 可以召唤裁判的视线 |
| 嘚瑟 | 占了便宜忍不住显摆 | 嘚瑟有一点收益，代价是暴露自己 |
| 模仿性欲望 | 想要别人想要的东西（吉拉尔） | 价值由他人的欲望决定 |
| 替罪羊 | 群体紧张时一起针对一个人会带来释放 | 周期性的"必须有人背锅" |
| 人情负担 | "我不想欠你的" | 帮助自动变成债 |
| 慷慨竞赛 | 抢着买单 | 用"给"来赢面子 |
| 旁观者效应 | 人越多越没人动 | 需要恰好一个人牺牲 |
| 法不责众 | 人数过了阈值，胆子突然变大（Granovetter 的阈值模型） | 同时违规的人够多就不罚 |
| 起哄 | 不只是看热闹，还推着别人往前（"跳！跳！"） | 旁观者可以加码 |
| 忍不住喊 | 看见别人要犯错，忍不住提醒或纠正 | 观众知道得比玩家多 |
| 越压越冒 | 不许笑、不许想（Wegner 的"白熊"） | 禁止不由自主的反应 |
| 作死 | 站在高处想跳；想推倒自己搭好的东西（"高处现象"） | 随时可以毁掉自己最珍贵的东西 |
| 想当按按钮的人 | 吹蜡烛、按引爆器、推第一块骨牌 | 触发者独得荣耀 |
| 留名与第一次 | 到此一游、首次发现、命名权 | 系统记住"第一个" |
| 被坑后想坑人 | 受害者变加害者（整蛊、入会仪式） | 被什么坑，就获得什么 |
| 玄学 | 从噪声里看出规律，并发明仪式 | 部分为真的隐藏规律 |
| 争宠 | 在一个生命面前的零和嫉妒（不同于眼红） | 一个会偏心的生物 |
| 生杀予夺 | 别人的命运在我一念之间 | 失败由另一个玩家裁决 |
| "他们怎么看我" | 对自身盲区的好奇 | 由别人定义你的属性 |
| 默契 | "我们想的一样！" | 不沟通的协调 |
| 领地 | 后座中间那条线、占座 | 看不见但人人都认的边界 |
| 试探底线 | 看不见的耐心上限，到底能过分到哪 | 隐藏的、共享的耐心值 |

### 0.5 示范：怎样让朋友不断给我"想扇他"的理由

"扇巴掌"只是出口。人想扇一个朋友时，通常同时满足：

1. 他**占了我便宜**（我有实际损失）；
2. 我**知道是他**（可以归因）；
3. 他**在嘚瑟**（面子受损，这是放大器）；
4. 我**现在够得着**（有机会窗口）；
5. 扇下去**有一点风险**（否则不刺激，也不值得讲）。

对应的世界规则：

- 让玩家之间能互相造成**小而真实**的损失（偷一点、挤一下、抢位置、坑一次），而不是只有系统能伤害你；
- 每次损失都在受害者那里**留下肇事者的名字**；
- 给**嘚瑟**一个小收益（比如嘲讽时还能再顺走一点），让占了便宜的人主动暴露自己；
- 设计周期性的**法外窗口**（隧道里的三秒、老师转身、停电）：窗口内报复没有代价，窗口外有风险；
- 让报复本身也给对方造成损失——于是他也有了理由。

这样系统每分钟都在生产"想扇人的理由"，不需要任何"扇人任务"。种子 B 就是这套规则最小的形态。

### 0.6 人为什么会把别人拉进来

"愿意叫朋友"本身也是几种冲动：

- **被坑了想坑回去，或坑下一个人**：整蛊、Rickroll 就是这样传播的。（种子 D、R3）
- **"你得看看这个"**：奇观。（所有种子的高光时刻）
- **"你来评评理"**：争议和站队。（种子 C 的债务纠纷、R4）
- **"这就是我们"**：认领式的共鸣，"@你弟"。（种子 B）
- **"缺一个人"**：人数需求。（A、B、C 都需要 3 人以上）
- **"我赌你做不到"**：挑战。（加速层里的挑战）
- **观众忍不住喊**：观众知道得比玩家多。（种子 A 的主播模式）

## 1. 第一阶段：24 个方向

按**因果链的形状**分组，而不是按人性分组——同一种人性可以接到完全不同的链上。每个方向只回答 8 点：人性 / 为什么忍不住 / 核心规则 / 第一次接触 / 连锁 / 单人或多人 / 传播 / 内容效率。

### A. 信息差：谁知道什么

#### 1. 盲点——你的死法写在你背上
- **人性**：知情者的快感、恶作剧、共谋、对自己的好奇、疑心。
- **为什么忍不住**：看见朋友背上写着"碰到水就死"，而他正往水边走——几乎没人能什么都不做：要么递水，要么憋笑，要么喊住他。同时，"我背上写的是什么"是一个无法忽略的缺口。
- **核心规则**：每个人身上挂着一条自己看不见、别人都看得见的死亡条件。
- **第一次接触**：五个人出生在一间普通的屋子里，先是互相读对方的条件，笑成一团，然后同时反应过来："那我背上呢？"有人开始殷勤地给别人递杯子。
- **连锁**：诱杀 → 有人死 → 死者变成看得见一切的鬼，能给一个活人一句提示 → 被提示的人开始怀疑那个一直递杯子的人 → "你告诉我我的，我告诉你你的"式的结盟 → 有人撒谎 → 从别人怎么躲你推断自己的条件 → 反过来利用它。
- **单人或多人**：4–8 人实时多人。另有"主播模式"：弹幕看得见主播的条件，主播自己看不见（见第二轮 R5）。
- **传播**：观众看到标签，又看到角色正走向死亡——这就是恐怖片"别进去！"的结构，十秒可懂，而且观众会忍不住喊。
- **内容效率**：条件是"已有动词 × 已有物体"的文字规则；多一件物体（雨伞），就多出一串条件（"在室内撑伞就死"）。AI 可以批量生成，人工只需挑出"能被诱发、看得出来"的那部分。

#### 2. 偷看——可以偷看，但被对视就暴露
- **人性**：窥探欲、被抓现行的刺激、将计就计。
- **为什么忍不住**：同屏多人最原始的行为之一，就是偷看别人的屏幕。与其禁止，不如给它一个价格。
- **核心规则**：每个人有私密信息（手牌、目标、地图）；你可以随时偷看任何人的，但如果那一刻对方正看着你，双方都会知道"你在偷看"。
- **第一次接触**：前两分钟大家规规矩矩；第一个人偷看成功，赢了；第二局所有人眼神乱飘，像课堂上传纸条。
- **连锁**：偷看 → 被抓 → 被抓的一方故意摆出假信息 → 偷看者上当 → 报复性的假信息 → 双重虚张（"我知道你知道我在看"）。
- **单人或多人**：2–6 人。
- **传播**：抓现行的一瞬间很好笑，而且人人现实中都干过。
- **内容效率**：可以叠在任何有隐藏信息的小游戏上，只需要一个"注视"判定。

#### 3. 玄学——每天一条隐藏规律，玩家自己发明仪式
- **人性**：从噪声里找规律（Skinner 的鸽子会自己发展出"仪式"）、分享秘诀、当先知的虚荣、争论。
- **为什么忍不住**：只要结果看起来和自己的动作有一点相关，人就会开始编仪式（抽卡玄学）；编出来的仪式一定要告诉别人。
- **核心规则**：结果由一条简单但隐藏的规律决定（比如"面朝北、刚跳过两次"），其余都是噪声；规律每天更换，全服同一条。
- **第一次接触**：今天莫名其妙连出三次好东西；你开始回想自己刚才做了什么；社区里冒出十几种理论。
- **连锁**：发现相关 → 发帖 → 别人照做 → 一部分人碰巧成功 → 仪式扩散 → 怀疑派做对照实验 → 真规律被找到 → 第二天全部作废。
- **单人或多人**：单人游玩 + 全服社区（异步）。
- **传播**：荒诞仪式本身就是梗（"全服都在对着墙转圈"）；每日刷新制造 Wordle 式的共同话题。
- **内容效率**：规律由程序生成，理论和梗由社区产出。

### B. 被谁看见：观察与裁判

#### 4. 还手才被看见——偏见的权威
- **人性**：擦边挑衅、忍、冤屈、"是他先动手的！"、告状、嫁祸。
- **为什么忍不住**：被戳到第三下，几乎没人能不还手；而"大人只看见我还手"，几乎是所有有兄弟姐妹的人的共同记忆。
- **核心规则**：一个权威会惩罚它看见的动作，它看不见之前发生了什么。
- **第一次接触**：三个孩子挤在车后座，爸爸的眼睛在后视镜里时有时无。A 戳了 B 一下；B 还手的一瞬间，镜子里的眼睛正好转过来："B！别闹！""是他先——""我不管谁先！"
- **连锁**：挑衅 → 忍 → 爆发 → 被抓 → 冤屈 → 专挑大人回头的瞬间激怒对方 → 告状（会把视线招过来，可能抓住对方，也可能抓住自己）→ 爸爸耐心见底："再闹就掉头回家！"（集体惩罚）→ 短暂停火 → 进隧道，黑三秒 → 全面开战。
- **单人或多人**：2–4 人（后座）到 6–10 人（教室）；也可以单人对 AI 熊孩子。
- **传播**：十秒可懂，不分文化，而且自带"@你弟"式的认领冲动。
- **内容效率**：一个场景、五六个小动作、一个视线系统。换一个场景就是一个新模式：教室、开会、考场、婚宴。

#### 5. 没人看见就不算——只有被目击的行为才生效
- **人性**："你看我！"、炫耀需要观众、坏事需要没人看、争夺注意力。
- **为什么忍不住**：做了神操作却没人看到，是游戏里最常见的憋屈之一；人会拼命拉别人来看，也会趁别人看别处时下手。
- **核心规则**：好事只有在至少一个其他玩家的视野里完成才计分；坏事只有在没人看见时才能完成。
- **第一次接触**：你完成了一次漂亮的跳跃，结算是 0 分，因为没人在看你。下一秒你开始喊："看我！看我！"
- **连锁**：求关注 → 别人故意不看（逗你）→ 你做更离谱的事来抢注意力 → 第三个人趁所有人都在看你时偷东西 → 被发现后互相指责"你干嘛看他" → 注意力变成可以交易的东西（"你看我一次，我看你一次"）。
- **单人或多人**：3–8 人。
- **传播**："注意力经济"的荒诞讽刺，好理解。
- **内容效率**：一个视野判定 + 少量行动。

#### 6. 生杀一念——你的失败由另一个玩家拍板
- **人性**：权力感、怜悯与残忍、求饶、记仇、人情。
- **为什么忍不住**：别人的命运在你手里，只要按一下——没有人会不认真对待；而被判的人一定会求饶，或者讨价还价。
- **核心规则**：任何玩家陷入致命失败时，由另一个指定玩家（离得最近的、害他的，或轮值的）在五秒内决定救不救。
- **第一次接触**：A 掉进坑里，屏幕中央弹出 B 的脸和两个按钮。A 在语音里疯狂求饶，B 故意拖到最后一秒。
- **连锁**：被放过 → 欠了人情 → 下次角色互换时还或不还 → 形成"仁慈 / 残忍"的名声 → 别人据此决定要不要靠近你 → 恩怨账越来越长。
- **单人或多人**：3–8 人。
- **传播**：求饶和"拇指向下"的瞬间，是天然的片段。
- **内容效率**：把任何失败状态变成一个社交时刻，不需要新关卡。

### C. 欠与还：互惠与义务

#### 7. 你欠我一次——帮助即债务，债务可以兑现
- **人性**：人情、互惠义务、被帮的负担、"我是为你好"式的强迫帮助、背叛。
- **为什么忍不住**：人对"欠人情"天生敏感；而手里握着别人的把柄却不用，几乎不可能。
- **核心规则**：任何帮助（拉一把、救起、递东西）都会自动生成一张债条；持有者可以在任何时候兑现：强制欠债人做一个动作（或接管他两秒）。
- **第一次接触**：大家本能地互相帮忙爬墙；十分钟后，有人第一次兑现债条，让朋友在悬崖边跳了一下。全场沉默，然后爆笑，然后所有人开始拒绝被帮。
- **连锁**：拒绝帮助 → 进度卡住 → 有人强行"帮忙"来制造债务 → 被帮的人满场逃 → 想报复就必须先帮对方（制造反向债务）→ "我们扯平了" → 债条可以转卖，第三个人买下你的债，你就归他了。
- **单人或多人**：3–6 人，合作中带利益冲突。
- **传播**："他救了我一命，然后用这份人情让我跳进岩浆"——需要一句话解释，但一句就够。
- **内容效率**：可以叠在任何合作任务上；债条是纯规则。

#### 8. 抢着请客——靠"给"赢
- **人性**：面子、慷慨竞赛（人类学里的夸富宴）、礼尚往来的压力、受之有愧。
- **为什么忍不住**：中国饭桌上的抢着买单，就是一场由面子驱动的真实比赛。
- **核心规则**：你不能给自己拿任何东西，只能送；收礼不能拒绝；分数是别人欠你、还没还的人情。
- **第一次接触**：大家以为是交易游戏，然后发现收礼才是坏事；有人收到一尊塞满整个仓库的巨型雕像。
- **连锁**：送 → 对方必须回一份更大的 → 升级 → 有人被"慷慨"压垮 → 礼物本身带着负担（要喂的宠物、每分钟响一次的钟）→ 转送。
- **单人或多人**：3–6 人；也可以好友间异步。
- **传播**："抢着买单"在中文语境里有很强的共鸣。
- **内容效率**：礼物是带属性的物体，规则只有一条"不能拒收"。

#### 9. 枪打出头鸟——第一名和最后一名都倒霉
- **人性**：怕出头、怕掉队、把别人推到前面的坏心眼、从众。
- **为什么忍不住**：一旦领先有危险，人会本能地往人群里缩，同时想把别人挤出去。
- **核心规则**：比赛中领先者和垫底者都会定期遭殃（闪电劈头名，怪物吃末名），终点直到最后才真正开放。
- **第一次接触**：一群人冲出起跑线，闪电劈中了第一个；所有人急刹车挤成一团，互相往前推；后面的怪物一靠近，又集体逃命。
- **连锁**：推人出头 → 被推的人记仇 → 两人结伴卡位 → 背叛 → 最后冲刺时规则翻转，突然人人都想当第一。
- **单人或多人**：6–20 人。
- **传播**：一群人拼命"不想赢"的画面，荒诞而且一看就懂。
- **内容效率**：一条赛道 + 两个惩罚者。

### D. 传染：一个人的行动改变别人的门槛

#### 10. 别人想要的才值钱——模仿性欲望
- **人性**：吉拉尔说的模仿性欲望（我们想要别人想要的东西）、跟风、囤积、泡沫与踩踏。现实版本就是 Labubu 式的抢购。
- **为什么忍不住**：看见别人抢一样东西，第一反应往往是"它是不是很值钱"。
- **核心规则**：物品的价值 = 此刻有多少人在看它、拿着它、追着它。
- **第一次接触**：满屋子破烂都不值钱；有人随手拿起一个马桶刷，它开始发光、标价上涨；另一个人冲过来抢；价格飙升；五个人为一个马桶刷打成一团。
- **连锁**：假装想要某样东西（拉盘）→ 众人跟风 → 高位抛售 → 接盘者愤怒 → 学会怀疑一切热情 → 有人逆向囤冷门货 → 冷门货突然被发现 → 新一轮踩踏。
- **单人或多人**：6–12 人；或者单人面对一群会跟风的 AI 顾客。
- **传播**：荒诞的抢购画面，加上对炒作文化的讽刺。
- **内容效率**：任何日常物件都能当商品，价值完全来自人。

#### 11. 法不责众——起义的阈值
- **人性**：怕当第一个、人多胆壮、临界点、告密。
- **为什么忍不住**：老师转身写板书时，全班蠢蠢欲动，但没人敢第一个动；一旦有人起头、又有人跟上，就是雪崩。
- **核心规则**：权威会惩罚违规者；但只要同一时刻违规的人数达到 N，权威就管不了（甚至被推翻）。
- **第一次接触**：老师背对全班，有人试探着扔出一个纸团，看有没有人跟；没人跟，他被罚站。下一轮，所有人开始用眼神和暗号约"数到三"。
- **连锁**：试探 → 先驱被罚 → 对"怂人"的怨气 → 约定 → 有人假装参与、实则告密领赏 → 信任崩塌 → 下一次更需要证明诚意。
- **单人或多人**：6–16 人；或主播 + 弹幕（刷屏人数达到 N 才生效）。
- **传播**：一个人站起来、全班没人跟——好笑；全班一起站上桌子——燃。
- **内容效率**：一个权威 AI + 少量违规动作。

#### 12. 我做到了，你敢不敢——以身作则的挑战（H-O-R-S-E）
- **人性**：炫耀、面子、不服输、激将、起哄。
- **为什么忍不住**："你肯定做不到"刺痛自尊；"我先做给你看"让挑战无法推脱。
- **核心规则**：任何人完成一个动作后，可以要求其他人照做；做不到的人得一个字母，集满五个出局；成功者获得下一次出题权。
- **第一次接触**：有人（纯属意外）从屋顶跳进了一个桶里，立刻宣布："你们来。"所有人都失败了，他笑到打滚。
- **连锁**：出题 → 模仿 → 失败被嘲笑 → 不服 → 出更难的题 → 为了出题而发明新动作 → 旁观者起哄选题。
- **单人或多人**：2–8 人，需要一个动作表现力强的沙盒。
- **传播**：花式投篮（Dude Perfect）式的片段，是已被验证的强传播形式。
- **内容效率**：内容由玩家发明；地图只需要提供"可以炫技的机会"。

### E. 守恒：总有一个东西必须在某人手里

#### 13. 烫手的礼物——诅咒必须被"收下"才能转移
- **人性**：甩锅、欺骗、侥幸、疑心、报复。
- **为什么忍不住**：拿着一个会炸的东西时，"给他！"几乎是身体反应。
- **核心规则**：世界上永远有一个诅咒；它只能在对方主动接受时转移，而且总是伪装成礼物——你分不清哪一份是。
- **第一次接触**：有人热情地递给你一个包装好的盒子。你犹豫了。你收下了。你开始冒烟。
- **连锁**：递 → 犹豫 → 收下或拒绝 → 所有礼物都变得可疑 → 真礼物也没人敢收 → 有人先送几次真礼物"洗白"信用，再递出诅咒 → 被坑的人记仇（不能直接传回，只能绕一圈）→ 诅咒的传播路径，就是全场的恩怨图。
- **单人或多人**：4–10 人。
- **传播**："他笑着递给我的时候，我就该知道。"
- **内容效率**：一个诅咒 + 若干外观相同的礼物。

#### 14. 谁拿着遥控器——控制所有人体验的那个位置
- **人性**：控制欲、滥用权力、公平感、抢夺。
- **为什么忍不住**：拿到遥控器（歌单、空调）的人，几乎一定会按自己的喜好来；其他人几乎一定想抢。
- **核心规则**：一个可以被抢的"遥控器"，持有者能改变所有人共享的环境（重力、灯光、地面材质、音乐节奏），但持有者自己也身处其中。
- **第一次接触**：拿到遥控器的人把地面变成了冰，自己也摔倒了；三个人扑过去抢。
- **连锁**：滥用 → 群起而攻 → 新持有者报复性滥用 → "你拿着的时候别针对我"式的联盟 → 背叛。
- **单人或多人**：3–8 人。
- **传播**：每一次环境变化都夸张，而且一目了然。
- **内容效率**：少数几个环境参数 × 一个可抢物品。

### F. 公地：共同投入，个人就能毁掉或白拿

#### 15. 最后一根稻草——共享的隐藏耐心
- **人性**：侥幸、贪、"不是我压垮的"、甩锅、试探底线。
- **为什么忍不住**：每个人都想再占一点便宜，只要自己不是最后那一下。
- **核心规则**：一个强大的存在（睡着的巨人、脾气差的老板）有一个隐藏的耐心值；每个人占的每一点便宜都在消耗它；它爆发时只惩罚压垮它的那个人。
- **第一次接触**：大家从睡着的巨人身上偷金币，越偷越大胆；巨人翻了个身，所有人僵住；有人又伸出了手。
- **连锁**：试探 → 越界 → 爆发 → 受罚者喊冤"拿得最多的明明是他！" → 下一局所有人抢着先拿，把风险留给后面的人 → 有人故意去挑衅巨人，让别人倒霉。
- **单人或多人**：3–8 人。
- **传播**：积木塔式的紧张，加上爆发的一瞬间。
- **内容效率**：一个耐心数值 + 各种小便宜。

#### 16. 一起搭的，一个人就能推倒——触发特权
- **人性**：作死冲动（Hames 等人 2012 年研究的"高处现象"：站在高处时突然冒出想跳的念头）、破坏欲、"我要当按下按钮的那个人"、集体投入与个人冲动的冲突。
- **为什么忍不住**：多米诺骨牌搭好以后，每个人都想亲手推倒第一块。
- **核心规则**：所有人一起搭一个会连锁的装置；任何人都可以在任何时刻触发它；触发者独得与倒下规模成正比的荣耀——但越早触发规模越小，而且会毁掉所有人的共同收益。
- **第一次接触**：大家搭了五分钟，有人手滑（或者不是手滑）碰倒了一块，半条骨牌应声倒下。所有人尖叫。
- **连锁**：提前触发 → 集体愤怒 → 拆掉肇事者搭的那段作为报复 → 派人看守 → 看守者自己离按钮最近，也最危险 → 越搭越大，诱惑也越大。
- **单人或多人**：3–10 人。
- **传播**：多米诺倒塌本身就是最原始的解压视频；"就差一点"的崩溃非常好剪。
- **内容效率**：一种可连锁的积木 + 一条"触发者独得荣耀"的规则。

#### 17. 谁先上——志愿者困境
- **人性**：旁观者效应（Darley & Latané 1968）、"凭什么是我"、搭便车、英雄主义。
- **为什么忍不住**：大家都等别人先上的僵局，本身就会让人憋不住笑。
- **核心规则**：每个障碍都需要恰好一个人付出代价（按住机关、先进黑屋、垫背），否则全体受罚；没有分配，也没有顺序。
- **第一次接触**：四个人站在门前，机关需要一个人一直按着。谁都不动。计时器在走。有人开始吹口哨。
- **连锁**：僵持 → 有人牺牲 → 记账："我已经上了三次了" → 讨价还价 → 有人赖账 → 集体受罚 → 秋后算账。
- **单人或多人**：3–6 人合作。
- **传播**："谁去点外卖"式的共鸣。
- **内容效率**：每个障碍都只是"需要一个人牺牲"的不同外形。

#### 18. 排队——秩序、插队与求情
- **人性**：公平感、插队的诱惑、占位、求情、撒谎。
- **为什么忍不住**：插队和被插队，是现实中最容易点燃情绪的小事之一。
- **核心规则**：一队人等一个稀缺的东西（派对上唯一的厕所），每个人有一个不断上涨的"急"条；可以插队，但会被后面的人看见。
- **第一次接触**：一个厕所，八个人，每个人的条都在涨。有人假装接电话，慢慢挪到了前面。
- **连锁**：插队 → 被揭穿 → 公审 → 有人真急了，求情 → 心软的人让位 → 被骗的人记仇 → 之后谁喊急都没人信 → 真急的人……出事了。
- **单人或多人**：4–10 人。
- **传播**：粗俗，但共鸣极强。
- **内容效率**：一条队列 + 一个计时条。

### G. 痕迹：你做过的事会撞上下一个人

#### 19. 坑你的那个坑归你了——陷阱遗传
- **人性**：被坑后想坑别人、恶作剧、留名、看"战绩"的虚荣。
- **为什么忍不住**：被坑之后最强的冲动，往往不是退出，而是"我也要让下一个人尝尝"。
- **核心规则**：被某个陷阱杀死时，你获得它的一份复制，可以稍作改动后放进世界，去坑后来的玩家。
- **第一次接触**：你捡起一枚金币，一架钢琴砸在头上。提示："钢琴之吻——某某放置，已坑 3214 人。现在它也是你的了。"
- **连锁**：被坑 → 获得 → 改良、放置 → 坑到人 → 收到战报 → 越有效的陷阱被复制得越多（像基因一样）→ 玩家学会识破 → 陷阱失效 → 变异出新陷阱 → 军备竞赛。
- **单人或多人**：异步多人（单人手感 + 全服生态）。
- **传播**：陷阱家谱；"我的坑干掉了某某主播"。
- **内容效率**：开发者只做陷阱零件，组合、伪装和选址全部来自玩家。

#### 20. 天下第一次——系统记住所有前所未有的事
- **人性**：想当第一、留名、"总得在某件事上是世界第一"、好奇"这样会怎样"。
- **为什么忍不住**：Infinite Craft 的"First Discovery"已经说明，只要系统告诉你"你是第一个"，人就会去试最荒谬的组合。
- **核心规则**：系统把每个事件记成"谁 × 用什么 × 对谁 × 在哪儿"；某个组合在全服第一次出现时，永久署上你的名字。
- **第一次接触**：你用一条鱼砸死了一只骑在牛背上的鸡，屏幕跳出："全服首次：被飞鱼击杀的骑牛之鸡——发现者：你。"
- **连锁**：追逐首次 → 常见组合被占完 → 尝试越来越离奇 → 截图炫耀 → 别人为了抢剩下的首次继续发明 → 首次清单本身成为社区话题。
- **单人或多人**：单人 + 全服共享记录；也可以多人。
- **传播**："全世界第一个做了这件事的人"天然适合截图。
- **内容效率**：需要一个动词和物体足够多的系统沙盒；事件名称可以由 AI 生成。

### H. 身体与语言

#### 21. 越不许越忍不住——身体出卖你
- **人性**：越压抑越冒出来（Wegner 的"白熊"实验）、憋笑、惊吓、字面意义上的"面子"。
- **为什么忍不住**："不许笑"会让人更想笑，尤其当朋友在专门逗你的时候。
- **核心规则**：摄像头或麦克风检测你不由自主的反应（笑、尖叫、眨眼），检测到就算输；其他人的任务是让你破功。
- **第一次接触**：四个人开着摄像头，一个人在讲故事，其他人拼命绷着脸。第一个人的嘴角动了。
- **连锁**：被逗笑 → 出局 → 发誓报复 → 下一轮全力逗他 → 学会"防逗脸" → 逗人技巧升级。
- **单人或多人**：2–8 人，尤其适合主播。
- **传播**："憋笑挑战"是已被验证的强传播形式；Don't Scream（麦克风检测到尖叫就重来）就是靠主播的反应走红的。
- **内容效率**：内容就是玩家的脸和朋友。

#### 22. 言出法随——说出口的话会被世界按字面实现
- **人性**：说错话、诱导别人说错话、许愿、禁词游戏、"你刚刚输了"（The Game）式的思维陷阱。
- **为什么忍不住**：告诉一个人"千万别说'好'"，他几乎一定会在十分钟内说出来；而你一定会想办法诱他说。
- **核心规则**：世界听着每个人说的话，并以最字面的方式实现其中一部分。
- **第一次接触**：有人随口说"我饿得能吃下一头牛"，一头牛从天而降压住了他。所有人安静了一秒，然后开始小心翼翼地说话——以及故意引导别人说"我快冻死了"。
- **连锁**：诱导对方说危险的话 → 中招 → 报复性诱导 → 所有人开始用奇怪的方式说话 → 沉默 → 任务需要沟通 → 不得不开口 → 口误。
- **单人或多人**：3–8 人语音；也可以用文字。
- **传播**："祸从口出"十秒可懂；Mage Arena（2025 年，喊出咒语名来施法）说明语音输入本身就有传播力。
- **内容效率**：内容 = 玩家说的话 × 有限的效果库；AI 负责把话映射到效果。

### I. 一个心灵：生物与商人

#### 23. 争宠——一只生物，几个人争它的爱
- **人性**：争宠式的嫉妒（不同于眼红）、保护欲、逗弄、嫁祸。
- **为什么忍不住**："狗狗会选谁"在短视频平台长盛不衰；被一个可爱的生命选中，是很原始的得意。
- **核心规则**：一只生物对每个人的好感是可见且零和的；它根据自己（不完美地）看到的东西，决定爱谁、恨谁。
- **第一次接触**：小动物跑向你，所有人开始讨好它；有人发现：趁它不注意踢翻它的饭碗，再躲到别人身后，它会记恨离得最近的那个人。
- **连锁**：讨好 → 嫁祸 → 它咬错了人 → 被咬的人报复性嫁祸 → 它越来越暴躁 → 所有人不得不先一起安抚它 → 暂时合作 → 再次争宠。
- **单人或多人**：单人（逗它、和它建立关系）或 3–5 人（争宠）。
- **传播**：动物反应本身就是流量形式；"它选了我"的得意非常好剪。
- **内容效率**：投入集中在一个生物的反应系统上，它和所有物体、所有玩家行为都能组合。

#### 24. 砍价——和一个会记仇、会八卦的商人
- **人性**：讨价还价、占便宜、面子、骗过聪明对手的快感。
- **为什么忍不住**：只要价格能谈，人几乎一定会砍；只要对面是 AI，人几乎一定会试着骗它。
- **核心规则**：所有交易都用自然语言谈；商人有情绪和记忆，还会把你的名声讲给其他商人听。
- **第一次接触**：你告诉商人你是他失散多年的儿子。他打了九折，然后告诉了全镇。
- **连锁**：骗 → 得手 → 名声传开 → 其他商人提防 → 换一个身份和谎言 → 谎言相互矛盾被揭穿 → 全镇对你涨价 → 你不得不修复名声。
- **单人或多人**：单人；也可以多人互相拆台。
- **传播**：Suck Up!（用语音说服 AI 居民开门）靠主播片段走红，这个形式已被验证。
- **内容效率**：内容是对话，由 AI 生成；人工只做少量商人性格和物品。

## 2. 第二阶段：回头审视

### 2.1 哪些其实是旧机制换皮

老实说，不少方向的核心规则早就存在，只是换了场景：

| 方向 | 其实是 | 新意在哪 |
|---|---|---|
| 13 烫手的礼物 | 烫手山芋 + 蟑螂扑克式的虚张声势 | 只有"必须被对方接受" |
| 14 遥控器 | 山大王（King of the Hill） | 权力作用于所有人的环境 |
| 15 最后一根稻草 | 积木塔、Clank! 类的推运气 | 惩罚只落在"最后一下" |
| 9 枪打出头鸟 | 橡皮筋机制和蓝色龟壳的显式版 | 让"不想赢"成为主体行为 |
| 12 H-O-R-S-E | 篮球、滑板里的同名游戏 | 几乎没有，只是搬进游戏沙盒 |
| 11 法不责众 | 一二三木头人 + 猎鹿博弈 | 人数阈值 |
| 6 生杀一念 | 斗兽场的拇指、真人秀投票 | 裁决者恰好是害你的人 |
| 3 玄学 | Noita 式的隐藏配方 + 每日种子 | 规律"部分为真"，鼓励仪式 |
| 20 天下第一次 | Infinite Craft 的首次发现 | 从合成扩展到动作事件 |
| 21 身体出卖你 | Don't Scream、憋笑挑战 | 让朋友负责逗你 |
| 24 砍价 | Suck Up! | 名声会在 AI 之间传播 |

旧不等于没价值——被验证过，说明这种冲动是真的。但它们不是"尚未被占领"的地盘；做它们，就是在跟已有作品拼执行力。

### 2.2 哪些听起来聪明，玩家大概率不会做

- **8 抢着请客**：玩家的第一反应是困惑，不是手痒。而且把人情明码标价，可能正好把"面子"换成了"价格"（Gneezy & Rustichini），情绪被账本挤掉。
- **5 没人看见就不算**："看我！"是真实的冲动，但"不看就不算"作为世界规则太反直觉。更适合做成局部规则（比如只有被看见的炫技才计分）。
- **10 模仿性欲望**：4–6 人时，模仿的链条太短，很可能退化成"大家抢那个最亮的东西"——一个普通的抢夺游戏。单人面对一群会跟风的 AI 顾客，反而更可能成立。
- **17 谁先上**：一开始真的会僵住，但熟人很快会形成"轮流来"的规矩，发动机就熄火了——除非每次牺牲的得失明显不对等。
- **2 偷看**：需要一个本身值得偷看的底层游戏；它自己不产生足够的欲望。
- **3 玄学**：玩家确实会编仪式，但攻略几小时内就会终结一切；每日刷新又让链条很短。
- **21 身体出卖你**：需要开摄像头，普通玩家的门槛和隐私顾虑都很大，更像主播专属。

### 2.3 我们仍被哪些"游戏必须有"限制住

几乎所有候选都默认：有"一局"，有一张地图，有角色，有胜负，大家同时在线，游戏待在自己的窗口里，观众只是观众，内容由开发者提供，输入是手柄——以及，**游戏必须公平**。

最后一条最值得推翻。很多发动机的燃料恰恰是不公：冤屈、偏心、被坑。关键不是消灭不公，而是让不公有一个**人类肇事者**。

### 2.4 更简单、更原始、更疯的版本

- **盲点** → 最原始：背上贴一张"踢我"。更疯：只有一个人背上写着"怪物"，而他自己不知道——所有人都躲着他，他还以为是自己有口臭。
- **还手才被看见** → 最简：只有两个按钮，"戳"和"装无辜"。更疯：权威由一个玩家扮演，他只能偶尔瞟一眼后视镜，因为他还得开车。
- **你欠我一次** → 更原始：去掉兑现，只留"强行帮忙"——被帮就是被占便宜。
- **陷阱遗传** → 更疯：陷阱不放在游戏里，而是做成一个链接发给朋友（见第二轮 R3）。
- **言出法随** → 最原始：全场只有一个禁词，说了就输。
- **多米诺** → 最疯：全服只有一个按钮（见 R4）。

### 2.5 母规则：很多候选其实是同一条规则的不同皮

| 母规则 | 一句话 | 属于它的候选 |
|---|---|---|
| M1 盲区 | 别人能看见你看不见的自己 | 1、2、21；真人秀里的撕名牌、酒桌游戏 Paranoia |
| M2 偏见的裁判 | 惩罚取决于谁被看见，而不是谁干的 | 4、11、23；部分 5、6 |
| M3 债 | 任何好处都会变成可以追讨的账 | 7、8、6、17；你们之前的"朋友担保" |
| M4 传染 | 一个人的行动降低别人的门槛、抬高东西的价值 | 10、11、12 |
| M5 守恒 | 总有一个东西必须在某人手里 | 13、14、15；你们之前的"力量守恒" |
| M6 痕迹 | 你做过的事会留在世界里，撞上下一个人 | 19、20、3 |
| M7 言即法 | 说出口的话变成规则 | 22、12（挑战就是给别人立的规则）；你们之前的"誓言" |
| M8 公地 | 共同投入，个人可以毁掉或白拿 | 15、16、17、18 |

两个观察：

1. **M1 和 M2 的共同根是"看见"。** M1 是别人比你更清楚你自己，M2 是裁判看到的比事实少。它们不增加任何资产，却直接生产误会、冤屈、共谋和戏剧反讽。两者还能合成一句话规则：**"老师只惩罚你背上写着的罪名；任何人都可以趁老师不看时往别人背上写字；你永远看不见自己的背。"**
2. 你们之前的誓言、担保、力量守恒，分别落在 M7、M3、M5 里。M1 和 M2 才是这一轮真正的新地盘。

### 2.6 推翻搜索空间：第二轮

如果去掉"一局、一张地图、同时在线、自己的窗口、观众只是观众"这些默认，会出现下面这些"这还算游戏吗"的东西：

- **R1 群聊里的禁词**：机器人住在群里，每个人都有一个禁词，只有别人知道。谁在正常聊天里说出了自己的禁词，机器人就当众宣布，并把他的群昵称改一天。（M1 + M7，住在日常生活里，零内容。）
- **R2 刺杀**：校园里流行的"Assassin"：每人有一个秘密目标，在没有目击者时用一把勺子"刺杀"对方，然后继承对方的目标。手机只当裁判，一局持续几周。
- **R3 恶作剧即安装包**：游戏本身就是一个你发给某个朋友的陷阱；他只有给下一个人做一个陷阱，才能"逃出去"。（M6，受害者变加害者，传播本身就是玩法。）
- **R4 全服一个按钮**：Reddit 的 The Button（2015）只有一个按钮和一个倒计时，却长出了派别、"邪教"和身份认同。每天一个两难按钮，按下的比例决定全服的后果。
- **R5 弹幕知道你的死法**：盲点的直播版。主播看不见自己的条件，弹幕看得见；主播只能问弹幕，而弹幕里有人帮，有人骗。
- **R6 朋友给你的属性**：你的角色属性由朋友匿名投票决定（"谁最莽？"）。Gas、tbh 都曾靠"朋友怎么看我"冲上 App Store 第一。
- **R7 别打开我**：一个靠"不打开"获胜的游戏，它会不断发通知诱惑你（"发生了点事……"）。逆反 + 好奇的纯形态。
- **R8 实时 Calvinball**：任何人都可以随时喊出一条新规则，由 AI 执行 30 秒。

诚实的评估：

- 大多数是**传播装置**，不是游戏本体。R4、R7 更像发行噱头；R2 有线下安全和规模问题；R6 除了有被拿来霸凌的风险，它的先例也爆得快、死得快——tbh 被 Facebook 收购后，因使用量低被关闭；Gas 被 Discord 收购九个月后关闭。这说明"对自身盲区的好奇"会被很快消费完，必须每局更新。
- 真正有价值的是三件事：**R5 可以直接成为种子 A 的主播模式**；**R1 是测试 M1 + M7 最便宜的方式**（一个群聊机器人，一个周末）；**R3 可以作为种子 D 的传播层**。
- 这一轮也说明：形式可以非常自由，但行为发动机本身，仍然落在少数几条母规则上。推翻搜索空间改变的是"它住在哪里"，不是"它为什么会动"。

### 2.7 用市场先例校准

| 先例 | 核心冲动 | 规则 | 说明了什么 |
|---|---|---|---|
| QQ 农场偷菜（2009 年前后）/ Steal a Brainrot（Roblox，2025） | 占便宜、报复 | 东西可以偷 | "偷"是被反复验证过的发动机。Steal a Brainrot 的细节很关键：偷东西的人会变慢、不能用道具，失主立刻收到通知，任何人打他一下东西就会回去——**小偷被做得又显眼又脆弱，追逃才会发生**。它在 2025 年 10 月达到约 2580 万同时在线。 |

| Buckshot Roulette（单人开发，销量 800 万以上） | 赌命、读人 | 一张桌子、一把霰弹枪 | 一张桌子、几乎没有内容，也能撑起高张力。 |
| Liar's Bar（2024，Steam 同时在线峰值超过 10 万） | 撒谎、赌命 | 吹牛纸牌 + 输了对自己开枪 | 老酒桌游戏加上肉身代价，就能传播。 |
| Don't Scream（2023 年抢先体验） | 越压越冒 | 麦克风检测到尖叫就重来 | 不由自主的身体反应可以当输入，对主播尤其有效。 |
| Mage Arena（2025） | 喊出来的快感 | 喊出咒语名来施法 | 说话本身就好笑、好传播。 |
| Suck Up! | 骗、说服 | 用语音说服 AI 居民开门 | AI 对话的片段能传播。 |
| Infinite Craft（2024） | 第一次、好奇 | 合成 + "首次发现" | "你是第一个"在组合空间里几乎用不完。 |
| Ultimate Chicken Horse（UCH） | 坑人、炫技 | 轮流往关卡里放东西；如果所有人都过了，谁都没分 | "难到别人过不去、自己又能过"会激发创造性的破坏。 |
| Gas / tbh | "他们怎么看我" | 朋友匿名投票 | 盲区好奇能冲上榜首，但消耗得很快。 |
| Chained Together（2024） | 共同命运、甩锅 | 所有人被铁链连在一起 | 一个人的失误拖垮所有人，吵架本身就是内容。 |
| Crowd Control | 起哄、恶作剧 | 观众花币改变主播的游戏 | 观众想要能亲自动手的按钮。 |

## 3. 第三阶段：值得灰盒测试的种子

### 3.1 怎么选

不打分，也不选第一名。选一组测试，让每一个即使失败也能告诉我们一些东西：

- **A 盲点**（M1）：对连锁和外部传播最有把握。
- **B 还手才被看见**（M2）：对欲望和成本最有把握。
- **C 你欠我一次**（M3）：新意最大，玩家会不会真的这样玩也最不确定。
- **D 坑你的坑归你了**（M6）：异步 / 单人手感的对冲，内容来自玩家。
- **外卡 言出法随**（M7）：AI 原生，上限高，先由真人扮演 AI 来测。
- 另有几层**可以叠在任何幸存种子上的加速层**（3.7）。

"听起来有创意"和"玩家大概率会做出有趣行为"并不是一回事（以下"把握"都是判断，不是数据）：

| 种子 | 听起来的新意 | 玩家会做出有趣行为的把握 | 主要依据 |
|---|---|---|---|
| A 盲点 | 中（桌游里早有"额头上的牌"） | 较高 | 额头扑克、Hedbanz、Paranoia、贴纸条恶作剧在真人中长期存在 |
| B 还手才被看见 | 低（听起来很普通） | 高 | 几乎所有人都在现实中这样做过 |
| C 你欠我一次 | 高 | 不确定 | 没有直接先例；"罚款即价格"提示可能适得其反 |
| D 陷阱遗传 | 中 | 中 | UCH、马里奥制造证明玩家爱给别人设坑；"遗传和演化"能否被玩家感知，未知 |
| 外卡 言出法随 | 高 | 不确定 | Mage Arena 证明语音输入好笑；"诱导别人说话"会不会自发出现，未知 |

B 值得注意：**听起来最普通的那个，可能最可靠。**

落选的理由：模仿性欲望、枪打出头鸟容易退化成普通的抢夺或赛跑；遥控器、稻草、烫手礼物是已知结构；身体出卖你、砍价已被占。它们可以作为幸存种子里的局部玩法回来。如果 A 和 B 都通过，下一步就测它们的合成（2.5 里那句规则）。

### 3.2 种子 A：盲点

**一句话规则**：每个人身上挂着一条自己看不见、别人都看得见的死亡条件。

**先例与空白**：额头扑克（Blind man's bluff：每人额头一张牌，看得见别人的，看不见自己的）、Hanabi、Hedbanz 说明"看不见自己"在桌面上是成立的。我没有找到把它做成"实时世界里的死亡条件"的主流电子游戏——但搜索有限，不代表不存在。

**最小可测版本**
- **第 0 步（一个晚上，不写代码）**：真人版。条件写在便利贴上，贴在背后（"拿着杯子时被叫全名就死""坐下就死""被拥抱就死""说'好'就死""独处十秒就死"）；给一个共同任务（十分钟内摆好一桌饭）；死者变成鬼，每回合可以给一个活人一句提示。
- **第 1 步（约 1–2 周）**：联网灰盒，4–6 人，一个房间，约 25 件物体、约 40 条条件，一个限时的共同任务，语音用 Discord。说话类条件在第一版先用文字聊天代替。

**十个维度**
- **欲望**：读到别人标签的瞬间，就会冒出"我要让他中招"；"我背上是什么"是一个强缺口。把握较高。
- **行为**：诱杀不需要任何提示。主要风险是过度谨慎（所有人都不动）。对策：限时的共同任务；加入"不动也会死"的条件。
- **反馈**：死亡即时、明确，而且所有人都知道是谁递的杯子。
- **连锁**：诱杀 → 鬼的提示 → 怀疑 → 结盟、交易信息 → 撒谎 → 推断 → 反杀。把握较高。
- **变化**：条件池 × 房间物体 × 人际关系，每局的故事都不同。风险是玩久了条件池被背熟，推理变成机械排除。对策：主题条件包；和别人相关的条件（"和某人距离一米以内就死"）。
- **人际传播**："他三分钟里给我递了七次水"——一个有明确反派的故事。
- **外部传播**：观众看到标签、看着人走向死亡，是天然的"别去！"。问题是玩家自己的画面里看不见自己的标签——所以需要观战镜头、多人视角，或者直接做成弹幕模式（R5）。
- **内容效率**：条件是作用在已有动词和物体上的文字规则；加一件物体，就多出一串条件。
- **成本**：很低，胶囊人就够。主要工程量是一个可靠的"事件 → 条件"判定系统。
- **长期退化**：可能出现"完全坦白"的联盟、原地不动、"先把一切都试一遍"等套路。对策：最后存活才算赢；元条件（"有人说出他的条件，他就死"——让诚实本身变得致命）；时间压力。

**最可能的失败方式**：变成逻辑题（推理太重），或变成等待游戏（所有人都太谨慎）；或者第一局很好笑，第三局就没新鲜感了。

**要观察的行为**：从开局到第一次主动诱杀的时间；每分钟的诱杀尝试次数；关于标签的谎言；结盟与背叛；死于诱杀与死于意外的比例；大笑的频率；结束后有没有人主动复述；再来一局的请求；**有没有玩家开始主动给别人设计条件**（非常强的信号）。

**停还是继续**：真人版里如果十分钟内没有人主动诱杀，或所有人都站着不动，核心假设就失败了。如果两分钟内就出现自发诱杀、玩家抢着要写条件、散场后还在讲，就进入数字灰盒。

**值得对比的变体**：死亡条件 vs 纯搞笑标签（"踢我"）；只有一个人是怪物而他不知道；杀人者继承受害者的条件。

### 3.3 种子 B：还手才被看见

**一句话规则**：一个只惩罚它看见的动作的权威；它永远看不见之前发生了什么。

**先例与空白**：搜到一个 Backseat Drivers（和看不见路的奶奶合作开车），前提不同。没有找到以"后座互戳 + 后视镜视线"为核心的作品（同样，搜索有限）。

**最小可测版本**
- **第 0 步（一个晚上，由真人扮演系统）**：三个玩家并排坐着，玩一个简单的 2D 小程序（可以戳人、偷零食），第四个人扮演爸爸，背对他们，随时回头，看见谁在动手就罚谁。甚至可以完全线下：一碗零食、三个人、一个随时回头的"家长"——就是一二三木头人加上戳人。
- **第 1 步（约 1 周）**：数字灰盒。俯视视角的车后座，三个孩子（玩家），一个 AI 爸爸；后视镜里的眼睛清楚显示视线方向，而且转头前眼神会先动（留一点预判空间）。五个动作：戳、偷零食、"我没碰你"（悬停）、告状、嘚瑟。一条耐心值，见底就"掉头回家"（全员输）。隧道 = 三秒黑暗。一趟旅程五分钟。

**十个维度**
- **欲望**：戳人不需要理由；被戳想还手接近生理反应。把握高。
- **行为**：非常自然。风险是玩家很快摸清视线的节奏：只在安全时挑衅，也只在安全时还手，变成对称的僵局。对策：视线会被声音吸引（还手比挑衅更响）；视线时机有一定随机性；告状可以主动召唤视线。
- **反馈**："B！别闹！"——即时、清楚、不公平。而这份不公平会被算到兄弟头上，而不是算到系统头上。
- **连锁**：挑衅 → 还手 → 被抓 → 冤屈 → 报复计划 → 嫁祸 → 告状 → 集体威胁。把握高。
- **变化**：单一场景下偏低到中等；但母规则可以直接搬到教室、开会、考场、婚宴，每个都是新模式。不同性格的家长也会带来变化。
- **人际传播**："我弟就是这样"——共鸣和回忆都极强。
- **外部传播**：十秒可懂，不分文化。
- **内容效率**：每加一个动作，都会和视线规则发生关系；新场景是便宜的换皮，再加上一种新的权威行为。
- **成本**：所有种子里最低。
- **长期退化**：老实说，它可能是一个很棒的 30 分钟派对游戏，而不是一个能玩 100 小时的游戏。扩展方向：教室模式（M2 + M4 的起义阈值）适合更多人；与 M1 合成（老师读你背上的罪名）。

**最可能的失败方式**：深度不够；视线 AI 被摸透；两人对局太对称。

**要观察的行为**：每分钟的挑衅次数；还手被抓的比例；自发的嫁祸；告状的使用；**"是他先动手的"这句话出现了几次**；大笑；再来一局；玩家有没有自己加家规。

**停还是继续**：如果几轮之后玩家不再挑衅（因为不划算），发动机就熄火了；如果大家只是狂按键、没有任何时机上的算计，说明规则没有产生决策。

### 3.4 种子 C：你欠我一次

**一句话规则**：任何帮助都会自动生成一张债条；债主可以随时兑现，强制欠债人做一个动作。

**最小可测版本**
- **第 0 步（一个晚上，桌面版）**：一个合作过河的棋盘游戏，某些缺口必须由另一个人帮忙才能过；每帮一次，帮忙的人得到一枚"人情筹码"；花掉筹码，就能指定欠债人的下一步。
- **第 1 步（约 2 周）**：4 人合作攀爬灰盒。帮助动作：托举、拉人、救起、递东西；债条显示在头顶；兑现会强制欠债人跳、松手、扔东西或行走两秒；债可以转卖；相互的债自动抵消（"扯平了"）。

**十个维度**
- **欲望**：握着别人的把柄不用很难；但需要系统让玩家第一次发现"兑现"这件事。中高。
- **行为**：最大的未知是——知道"帮助 = 债"以后，玩家还会不会互相帮？必须让帮助不可或缺；"强行帮忙"是最好笑的那条边。
- **反馈**：被强制的动作看得见，也知道是谁干的（"他用人情让我跳了"）。
- **连锁**：帮助 → 债 → 滥用 → 拒绝被帮 → 强行帮忙 → 想报复就得先帮对方 → 扯平 → 债务买卖。
- **变化**：中高，取决于底下的合作玩法。
- **人际传播**："他救了我，然后……"是好故事。
- **外部传播**：需要一句话解释，不如 A、B 一眼就懂。头顶的债条能帮上忙。
- **内容效率**：可以叠在任何合作玩法上，但合作底子本身需要足够多"必须求人"的时刻——这部分就是内容。
- **成本**：中等（需要一个合作移动的灰盒）。
- **长期退化**：熟人之间可能收敛到"谁都别帮"或"帮完立刻抵消"的默契。"罚款即价格"的风险也在这里——不过在这个设计里，把人情明码标价恰恰就是笑点。只有测试能回答。

**最可能的失败方式**：被强制行动的感觉是憋屈而不是好笑；或者玩家干脆不再互相帮，合作直接崩掉。

**要观察的行为**：第一次兑现前后的帮助频率；强行帮忙的尝试；债务交易；"扯平了"的时刻；被强制时是笑还是恼。

### 3.5 种子 D：坑你的坑归你了（异步）

**一句话规则**：被哪个陷阱杀死，你就得到那个陷阱，可以改一点后放进世界，去坑下一个人。

**最小可测版本**
- **第 0 步（约 1–2 周）**：2D 网页灰盒，一条走廊式关卡，约 10 种陷阱零件（假金币、落物、暗门、假出口、按钮……），先放 20 个开发者陷阱；邀请 30–100 名测试者在一周内异步游玩。死亡即获得陷阱；放置时可以改伪装和位置；定期推送战报。
- **第 1 步**：观察种群动态——会不会出现陷阱"家族"，玩家会不会回来看自己的战绩。

**十个维度**
- **欲望**：被坑后"我也要坑人"的冲动很强；放陷阱本身就是创造性的恶作剧。
- **行为**：玩家会不会放？大概率会（UCH、马里奥制造的经验）。会不会回来？战报是主要的拉力。
- **反馈**：死亡是即时的；战报是延迟的（异步），弱一些，但能带来回访。
- **连锁**：链条在种群层面，而不是人际层面——人际情绪更弱，生态变化更强。
- **变化**：如果变异空间足够大，会是一个会演化的生态，长期变化可能很高。
- **人际传播**："我的坑坑了 3000 人"；把某个陷阱做成链接发给朋友（R3）。
- **外部传播**："看这个坑的家谱"；主播死在观众的陷阱里。
- **内容效率**：陷阱全部来自玩家。
- **成本**：中低；需要异步存储陷阱的后端，以及对陷阱文字的审核。
- **长期退化**：挫败感；看不见的不公平陷阱。每个陷阱都必须"事后看是公平的"——这样才是良性冒犯。冷启动需要足够的人口。

**最可能的失败方式**：挫败大于好笑；陷阱越来越不公平；玩家被坑几次就走；或者人口太少，生态根本长不起来。

**要观察的行为**：死后放置陷阱的比例；为了看战绩的回访率；每个陷阱的击杀数；变异的多样性；"这不公平"类的抱怨。

### 3.6 外卡：言出法随

**先测什么**：玩家会不会在十分钟内开始把"说话"当武器——诱导别人说出危险的话？

**怎么测（由真人扮演 AI）**：4 个人开语音，玩一个极简灰盒；一个人类主持人在后台听，有人按字面说出某个触发短语时，手动触发效果（约 30 种：落下一头牛、冻住一个人、变小……）。一个晚上就够。

**为什么值得**：如果这种行为出现了，再投入语音识别和 AI 映射才有意义；如果没出现，省下的是整条 AI 管线。

### 3.7 加速层：不是种子，是乘数

这些东西本身不构成发动机，但可以叠在任何幸存的种子上，放大欲望或传播：

- **有收益的嘚瑟**：嘲讽能多拿一点点，代价是把自己标记成肇事者。它会直接放大对方的报复欲。
- **挑战与起哄**：任何人都可以要求别人照做；拒绝是公开的（头上长出鸡毛）。
- **天下第一次**：系统记住"第一个"，把奇怪的行为变成可以炫耀的东西。
- **主播模式**：让弹幕比主播知道得多（弹幕看得见主播的标签，看得见爸爸马上要回头）。
- **面子外溢**：输家的称号由赢家决定，并带到下一局。

### 3.8 测试方法

**顺序**：同一个晚上跑 A（便利贴）和 B（真人扮爸爸）→ C（桌面版）→ 外卡（真人扮 AI）→ D（网页异步，需要一周）→ 幸存者做数字灰盒。

**共同的观察方法**
- 在征得同意的前提下录像，事后按行为编码：非设计目标的出现、报复、大笑、争执、"再来一把"、复述、向别人解释，以及第 5–10 局时有没有出现固定套路。
- 第二天问一句"昨天发生了什么"，数他们主动讲出的故事——比问"好玩吗"可靠得多。
- 每个种子测 2–3 组**真实的朋友组**，而不是开发者自己，也不是陌生人。
- 这些测试只能发现"有没有"的强信号，分辨不出"好一点还是差一点"的弱差异。

**先写好停还是继续的标准，再开始测**，避免事后为已经投入的方案找理由。

### 3.9 我不确定的地方

- **恶作剧类发动机能不能留住人。** 派对游戏常常是爆发式的；A 和 B 都可能是"很好笑的一晚"，而不是"每周都想玩"。
- **陌生人会不会像朋友一样玩。** 这些发动机很依赖关系：朋友之间是好笑，陌生人之间可能变成残忍。A、B、C 可能天生是"和朋友玩"的游戏——这会直接影响发行方式（依赖朋友组和主播，而不是匹配）。
- **文化差异**：车后座的兄弟战争几乎全世界通用；抢着买单主要在中文语境里好笑。
- **引用的证据**说的是人在实验和市场里的行为，不是我们这些具体设计的效果。它们只能说明"这种冲动是真的"，不能说明"这条规则会好玩"。
- 商业化、平台限制（比如微信对机器人的限制）这一轮都没有考虑。

**如果只能做一件事**：找两三组朋友，用便利贴和一个真人扮演的爸爸玩一个晚上。成本是一个晚上和一叠便利贴，得到的信息会比继续头脑风暴多。
