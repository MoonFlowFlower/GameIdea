# 复查：上一轮的"新规则"大多已经有人做过

> 用户指出："只要你不看他，他就看不见你"就是哭泣天使那类怪物。这一轮先复查，再留下真正没找到先例的。
> 2026-09-26

## 复查结果

| 上一轮的点子 | 实际情况 |
|---|---|
| 只要你不看他，他就看不见你 | 哭泣天使 / SCP-173（你不看它才能动）的反面，就是 SCP-096 和《我的世界》的末影人：你一看它，它就来找你。"别看它"是恐怖游戏的老套路。 |
| 说出的话变成真的气泡 | 2025 年全球游戏创作节（Global Game Jam）有一个作品叫 Speech Bubbles：一只老鼠的吱吱声会变成气泡，当平台、当推力。 |
| 说曹操，曹操就到 | 对着镜子喊三遍 Bloody Mary 就会召唤出来，这在恐怖游戏里是常见桥段。 |
| 不往下看，就不会掉 | 只在过场动画里当笑料用过，没找到把视角做成重力开关的。**保留**，但它更像一个关卡。 |

**问题出在哪**：我只按具体玩法搜了游戏名，没有对照整类游戏的老套路。越符合直觉的规则，越可能早就被恐怖游戏、派对游戏用过。

**以后的查法**：每个点子先对照三处——TV Tropes 上的相关条目、恐怖和派对游戏的常见套路、Roblox / itch / 游戏节作品。都没找到的才拿出来，并写清楚查到了哪一步。

## 通过复查的：阿嚏——有人喊你的名字，你就会打喷嚏

**直觉从哪来**
- 东亚都有"打喷嚏是有人在说你"的说法；西方有"耳朵发烫"（有人在背后议论你）。
- 躲着的时候憋喷嚏，是电影和生活里人人都有过的桥段。

**它改的是躲猫猫的核心动作**
- 找的人不再是"用眼睛找"，而是"喊名字"。
- 藏的人不再是"躲好别动"，而是"憋住别打喷嚏"。

**一局怎么玩**（1 个找的人 + 4 个藏的人，一栋房子）
- 找的人满屋子喊名字，真的喊出来（只需要识别房间里这几个名字，识别不了时也可以先用按键代替）。哪里传来"阿嚏"，就往哪里扑。
- 被喊到名字的人会想打喷嚏。可以捏住鼻子憋着（按住一个键），但憋的时候不能动，而且憋得越久，下一个喷嚏越响——最后那一下能把柜门崩开。
- 灰尘、胡椒、猫毛会让所有人更想打喷嚏，所以找的人可以撒胡椒、抖窗帘、把猫抱进来。
- 藏的人之间也能互相喊名字：把找的人引到队友那边，或者纯粹坑队友一下。

**为什么会一局接一局**
- 每一次"憋还是不憋"都是赌。
- 朋友之间喊名字，会变成出卖和报复。

**节目效果**
- 找的人在客厅里大喊"迈克！迈克！"，洗衣机里传出一声闷闷的"阿……阿……阿嚏"。
- 有人憋了二十秒，最后一个喷嚏把衣柜门崩开了。

**同一个想法还能往下延伸：你最大的敌人是自己的身体**
- **哈欠会传染**：找的人对着房间打个大哈欠，附近藏着的人也会跟着打出声来。
- **腿蹲麻了**：在同一个地方蹲太久，腿会麻，跑起来一瘸一拐。
- 这两条我也查了，都没找到做过的。
- 不打嗝：打嗝会暴露位置，已经有游戏节作品 The Drunk Heist 做过。

**成本**：低。识别几个固定名字的语音关键词，技术上很成熟。

**要验证的**：玩家会不会觉得"被喊名字就打喷嚏"不公平？关键在于憋喷嚏的那几秒是好笑还是憋屈。
